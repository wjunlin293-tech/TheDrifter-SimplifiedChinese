  The Drifter 简体中文汉化

【安装】

  1. 完全退出游戏
  2. 双击「安装.bat」
  3. 提示"安装完成"后启动游戏

  脚本会自动找到游戏目录。如果没找到，把游戏目录拖进窗口再回车即可。
  （游戏装在 C 盘 Program Files 时会弹管理员权限，点"是"）

【如果游戏里还是英文】

  Options -> Language -> 选择 简体中文

【卸载】

  双击「卸载.bat」，还原成英文原版。
  原版文件备份在游戏目录的「_汉化备份」文件夹里，别删。

【注意】

  Steam 更新游戏、或用了"验证游戏文件完整性"之后，补丁会被覆盖，
  重新双击一次「安装.bat」就行。

【汉化内容】

  · 全部 9803 条文本，含剧情、物品、线索、菜单、成就
  · 人名地名保留英文（Mick、Roth、Trinity Biotech……）
  · 像素字体，与游戏原版风格一致
  · 修复了引擎不给中文断行导致字幕跑出屏幕的问题

【遇到问题】

  到发布页提 issue，附上：
  · 游戏版本（Steam 属性里可以看）
  · 出问题的截图
  · 安装时窗口里的报错文字
